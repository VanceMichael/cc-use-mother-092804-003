# 环湖马拉松报名与赛道保障

协调大型马拉松报名分区、医疗接驳保障、计时结果和完赛权益。

## 参与方与事实

主要参与方包括赛事组委会、参赛选手、医疗救援人员、志愿者、接驳调度人员。领域资料记录以下已经确认的事实：

- 衡水湖马拉松吸引约一万二千名中外选手
- 赛事采用三枪五区分时起跑
- 现场设置医疗点、救护车和接驳保障体系

## 业务约束

- 分区容量
- 医疗资源
- 现场事件顺序
- 成绩封存
- 权益发放

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/marathon_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
